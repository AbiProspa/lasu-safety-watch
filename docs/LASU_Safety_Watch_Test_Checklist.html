1. General & navigation

Open the live site on a laptop, then repeat key checks on a phone.

#What to doExpected resultPass
1Open the home page.Page loads over https with the LASU crest, navy colours and no errors.
2Look at the browser tab.The crest icon (favicon) shows; title reads "LASU Safety Watch".
3Click each navbar link: Report incident, Live map, Safety Center, Track report.Each page opens; the current page is highlighted in the navbar.
4Click the logo from any page.Returns to the home page.
5Click the red Emergency SOS button in the navbar.Opens the Safety Center and scrolls to the SOS panel.
6On a phone, tap the menu (☰) icon.Menu opens with the 4 links + Log in; every item is easy to tap.
7Scroll to the footer and tap an emergency number.Phone dialler opens with that number.
8Visit a page that does not exist, e.g. /abc.A "Not Found" page appears (no crash / no code shown).

2. Home page

#What to doExpected resultPass
9Read the hero section.Headline "Report it. We'll act on it.", one Report an Incident button and a Track existing report link.
10Check the "What do you need to report?" card.6 categories with the unit that handles each and a live "x open" count; "Live" indicator and last-report time.
11Tap a category (e.g. Security Incident).It expands to show its specific types (Theft, Cult activity, …). Tapping again closes it.
12Tap a specific type (e.g. Cult activity).Report form opens with that category and type already selected.
13Check the numbers strip under the hero.Shows reports received, resolved, this week, average resolution time.
14Check "Recently verified" list.Only verified/in-progress/resolved reports; never Harassment & GBV; clicking one opens its tracking page.
15Click "Open live map".Goes to the Live map.

3. Report an incident (no login)

Log out first so you test as an anonymous visitor.

#What to doExpected resultPass
16Open Report incident and click Submit without filling anything.Form is not sent; required fields (type, title, description, location) are flagged.
17Choose each of the 6 categories in turn.The "Specific type" list changes to match the category.
18Pick a severity (Low / Medium / High / Critical).Selected option is highlighted.
19Type a title shorter than 5 characters and submit.Error message asks for a longer title.
20Choose a Campus location (e.g. Senate Building).The map jumps to that place and drops a red pin.
21Tap somewhere else on the map, then drag the pin.Pin moves; message confirms the new position.
22Click "Use my location" and allow location.Pin moves to your real position. If you deny, a friendly message says to tap the map.
23Set "When did it happen?" to a future time.Not allowed (date must be now or earlier).
24Attach a photo under 5 MB.A small preview appears next to the upload box.
25Attach a non-image file (e.g. a PDF) or an image over 5 MB.Submission is rejected with a clear error.
26Tick "Report anonymously" and submit a full report.Success page with a tracking code like LSW-XXXXXX and a Copy code button.
27Click "Copy code", then "Track this report".Code is copied; tracking page shows status "Received" and the first update.
28Start a Harassment & GBV report."Report anonymously" is ticked and locked; a note says these reports are always anonymous.
29Fill in the optional follow-up contact and submit.Report is saved; only the responsible unit can see the contact.
30Submit more than 10 reports within one minute.Extra submissions are blocked ("Too many requests") - spam protection.

4. Track a report

#What to doExpected resultPass
31Enter a valid code on Track report.Shows category, location, date, a 4-step progress bar and the update timeline.
32Enter the same code in lower case (lsw-xxxxxx).Still found.
33Enter a wrong code.Friendly "No report found" message.
34Track a Harassment & GBV report.Title is hidden ("Confidential report").
35After staff add an internal note (section 8), track the report again.Internal notes are NOT shown; public notes are.
36Track a report that staff marked Rejected.Message explains it was closed without action.

5. Live map

#What to doExpected resultPass
37Open Live map.Map of LASU Ojo campus with coloured pins; larger dots for critical reports.
38Click a pin.Popup shows type, title, location, time, status and a link to its tracking page.
39Click a category in the filter list.Those pins disappear/reappear; counts beside each category are correct.
40Change "All time" to "Last 7 days".Only recent reports remain.

6. Safety Center & SOS

Use a phone for these if possible. Tell Campus Security first if testing on the real system.

#What to doExpected resultPass
43Open Safety Center.Compact header, SOS panel (only the SOS button is red) and "Who to call" list.
44Tap SOS, then tap Cancel during the countdown.Countdown 5→0 shows; Cancel stops it and nothing is sent.
45Tap SOS and let it finish (allow location)."Alert sent to Campus Security" with a reference code; exact GPS is used.
46Repeat but block location permission.Alert still sends, with a message that the location is approximate.
47Type a note (e.g. "Fight at Hostel B gate") before tapping SOS.The note appears in the SOS report on the staff side.
48Tap SOS more than 5 times within a minute.Extra alerts are blocked; message asks you to call Campus Security.
49Tap "Can't use SOS? Call Campus Security" and each number in Who to call.Phone dialler opens with the right number.
50Read "SOS or report?" and Stay safe on campus.Content is readable; Report an Incident button opens the form.

Before going live

  • Change every demo password (Users & roles) or disable demo accounts.
  • Replace the 0800000000x phone numbers with official LASU numbers (config/lsw.php).
  • Check the landmark map coordinates in config/lsw.php against the real campus.
  • Set SEED_DEMO_REPORTS=false in Railway variables.
  • Tell Campus Security before testing SOS on the live system.
